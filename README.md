# 🍳 Everyday Recipes — Recipe Explorer

A modern, editorial culinary notebook & world gastronomy exploration web platform built with **Next.js 16 (App Router)**, **React 19**, **TypeScript**, and **Tailwind CSS v4**.

---

## 📂 Project Location

The active Next.js application is located in the [`Nextjs_project_02/recipie_explorer`](./Nextjs_project_02/recipie_explorer) directory.

### Quick Start

```bash
cd Nextjs_project_02/recipie_explorer
npm install
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) to see the application.
